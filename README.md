# Engagement Invitation

Interactive engagement invitation with gatefold open, curtain reveal, countdown, scratch-to-reveal, maps, music, RSVP and WhatsApp sharing.

## Quick start

```bash
npm install
npm run dev
```

- Invitation (opens on TAP TO OPEN): [http://localhost:5173/](http://localhost:5173/)
- Admin: [http://localhost:5173/admin](http://localhost:5173/admin) — PIN: `admin`

## How to edit

1. Open **Admin** → enter PIN `admin`
2. Click **Edit** (or **New**)
3. Fill names, dates, venue, photos, WhatsApp number, etc.
4. Click **Save**
5. Open the invitation link — your changes appear immediately

No database or Supabase setup required. Details are saved in your browser.

## Stack

React · Vite · TypeScript · Tailwind CSS · Framer Motion
